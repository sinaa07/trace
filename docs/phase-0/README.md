# Phase 0 — Architecture Freeze

These documents are the approval boundary before any Phase 1 feature logic. Record decisions here, then translate approved contracts into Pydantic, SQLAlchemy, API routes, and React types.

- `core-schemas.md`: six required domain schemas.
- `api-contracts.md`: specified endpoint groups.
- `graph-model.md`: Neo4j node/relationship decision record.
- `synthetic-evidence-spec.md`: controlled railway evidence dataset format.
- `evaluation-and-ground-truth.md`: metrics and labelled truth-set design.
